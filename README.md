## 📌 Project Overview
This project is submitted as part of the **Future Interns - Data Science & Analytics Internship (April 2025)**.  
The goal is to analyze UK road accident data and create a dashboard that reveals:

- High-risk accident locations  
- Common causes and patterns  
- Safety improvement insights

Data visualization is done using **Power BI**.

---

## 🛠️ Technologies & Tools Used
- 📊 **Power BI** – Dashboard creation and visualization  
- 🧮 **Microsoft Excel** – Initial data formatting  
- 🔢 **Kaggle Dataset** – Real-time road accident records

---

## 📁 Dataset Files

```
├── accidentsbig.csv      # Accident details: location, severity, date, etc.  
├── casualtiesbig.csv     # Information on people injured or killed  
├── vehiclesbig.csv       # Vehicle types, maneuvers, and roles
```

---

## 🧹 Data Cleaning & Preparation

- Converted CSV format using proper delimiter (comma)  
- Removed corrupted rows and ensured proper column alignment  
- Merged all three datasets using `Accident_Index` as key  
- Verified relationships in Power BI model view

---

## 📊 Dashboard Highlights

- Filtered by **Accident Severity**, **Day of Week**, **Urban/Rural**, etc.  
- Identified **hotspots** using map visuals  
- Severity trends by **weather**, **light**, and **vehicle type**

## 🎯 Key Insights

- 🛵 **Two-wheelers** are involved in many fatal accidents  
- 🌃 Poor lighting significantly increases accident severity  
- 📍 Most high-risk areas are in **urban regions**  
- ☀️ Surprisingly, clear weather still accounts for most accidents
